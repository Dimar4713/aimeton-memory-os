# AIMETON Cognitive Operations Complex: Four-Axis Coordination Model v0.2

## Scope and claim status

External name: **AIMETON Cognitive Operations Complex** (short: **AIMETON CogOps Complex**, namespace `AIMETON.COGOPS`). This document proposes a falsifiable engineering hypothesis, not a claim of established scientific novelty.

## Core hypothesis

A reliable agent context is not a ranked set of relevant fragments. It is a **coordinated configuration** of four non-substitutable projections of the same operational reality:

`V` vertical purpose/scope; `R` role, authority and responsibility; `O` ontology, state and temporal validity; `A` associative evidence, precedents and similarity.

For a request `q` and live state `s`, `C = K(q,s,V,R,O,A,P,E)` is admissible only when mandatory projections are present, mutually compatible, policy-permitted and linked to primary evidence `E` under policy `P`. A high score on one projection cannot compensate for a hard failure of another.

## Bidirectional operator

`Write_K(input)` preserves raw evidence, extracts independently addressable infoblocks, projects each onto `V,R,O,A`, records cross-projection links and leaves ambiguity unresolved.

`Read_K(q,s)` compiles a bounded ContextBundle from permitted projections, applies hard constraints before association/ranking, records excluded candidates and returns escalation rather than a misleading operational context when mandatory coordination fails.

This is distinct from four filters: filters independently discard items; `K` establishes and tests relations between projections of the same claim/action context.

## Falsifiable predictions

Against identical corpus, model and token budget, full `AIMETON.COGOPS` should improve critical-evidence coverage and verifier-accepted actions while keeping policy/stale/rejected leakage at zero, compared with: (A) hybrid RAG, (B) RAG plus policy filter, and (C) four-axis retrieval without coordination.

If it does not improve those outcomes, the four-axis coordination claim must be downgraded to an organisational vocabulary rather than treated as an architectural advantage.

## Boundaries

The model neither claims a full fractal runtime nor fixes a universal number or semantics of diagnostic gates. Gate topology is a versioned research registry, not a public stable API. LLMs cannot promote authority, policy or evidence status and cannot bypass governed write/action paths.
