# Contributing

Thank you for contributing.

## Principles

- Preserve evidence provenance and immutable references.
- Never bypass policy, compatibility checks, verifier, or trace.
- Do not add secrets, real customer data, access tokens, private links, or production configuration.
- Keep changes narrow, typed, testable, and documented.
- Mark uncertain semantics as OPEN rather than inventing a default.

## Pull requests

Every PR must state scope, invariants affected, tests/fixtures, and rollback or rejection behaviour. Contributions are submitted under Apache-2.0 unless explicitly agreed otherwise.
